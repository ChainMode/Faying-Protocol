# Faying Protocol/1.0 協定規範

這裡是 Faying Protocol/1.0 的繁體中文正式規範（Final，發布於 2025-10-25）。協定正文按章拆成 11 個檔案，章號兩位編號、檔名帶章名；術語表、參數預算以及協定的產出過程材料以附錄形式編入，方便開源參與者既讀得懂協定本身，也看得清它是怎麼一步步定下來的。

英文規範在 [`../../../en/specification/2025-10-25/`](../../../en/specification/2025-10-25/)，為**單檔案結構**（協定正文全部內聯在 `Faying-Protocol-1.0.md` 一個檔案裡，含 §1–§11 與附錄 A/B）；與中文的對應是**章節錨點層面**的對應，而非檔案逐一對應。本繁體中文版以簡體中文（zh-CN）為正源；繁體版若與簡體正源有歧義，以簡體中文為準。

## 怎麼讀

如果你是第一次接觸，建議按 §1 → §11 順序讀一遍正文，再翻附錄。術語不清就查附錄 A，逾時/預算等具體數值看附錄 B。
