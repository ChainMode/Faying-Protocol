# Faying Protocol/1.0 프로토콜 규격

여기는 Faying Protocol/1.0의 한국어 정식 규격(Final, 2025-10-25 공개)이다. 프로토콜 본문은 장별로 11개 파일로 쪼개었으며, 장 번호는 두 자리 편번, 파일명에는 장 이름을 붙였다. 용어표, 파라미터 예산, 그리고 프로토콜의 산출 과정 자료는 부록 형태로 엮어, 오픈소스 참여자가 프로토콜 자체를 읽어 이해할 수 있을 뿐 아니라 그것이 어떻게 한 걸음씩 정해졌는지도 들여다볼 수 있게 했다.

영문 규격은 [`../../../en/specification/2025-10-25/`](../../../en/specification/2025-10-25/)에 있으며 **단일 파일 구조**다(프로토콜 본문 전체가 `Faying-Protocol-1.0.md` 한 파일에 인라인되어 있고, §1–§11과 부록 A/B를 포함한다). 한국어판과의 대응은 **장·앵커 수준**의 대응이지 파일 일대일 대응이 아니다. 간체 중국어판(zh-CN)과 차이가 있을 경우 간체 중국어판을 정본으로 한다.

## 어떻게 읽는가

처음 접한다면, §1 → §11 순서로 본문을 한 번 읽고 부록을 펼쳐 보길 권한다. 용어가 불분명하면 부록 A를 찾고, 타임아웃·예산 등 구체적 수치는 부록 B를 본다.

각 본문 파일 front matter의 버전 번호는 모두 이것과 일치한다. 본 버전은 1.0 정식 발표 판차이며, 초안 작업 영역에서 본 디렉터리로 전체가 이전 완료되었다. 한국어·영문은 같은 한 차례의 커밋으로 함께 발표되며 단독으로 발표하지 않는다. 이후 정오(errata)는 §1.7.4에 따라 새 발표 일자 판차로 처리하며, 프로토콜 버전 번호는 바꾸지 않는다.
