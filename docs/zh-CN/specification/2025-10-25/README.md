# Faying Protocol/1.0 协议规范

这里是 Faying Protocol/1.0 的中文正式规范（Final，发布于 2025-10-25）。协议正文按章拆成 11 个文件，章号两位编号、文件名带章名；术语表、参数预算以及协议的产出过程材料以附录形式编入，方便开源参与者既读得懂协议本身，也看得清它是怎么一步步定下来的。

英文规范在 [`../../../en/specification/2025-10-25/`](../../../en/specification/2025-10-25/)，为**单文件结构**（协议正文全部内联在 `Faying-Protocol-1.0.md` 一个文件里，含 §1–§11 与附录 A/B）；与中文的对应是**章节锚点层面**的对应，而非文件逐一对应。中英文出现歧义时以中文为准。

## 怎么读

如果你是第一次接触，建议按 §1 → §11 顺序读一遍正文，再翻附录。术语不清就查附录 A，超时/预算等具体数值看附录 B。
