# Faying Protocol/1.0 プロトコル仕様

ここは Faying Protocol/1.0 の日本語正式仕様（Final、2025-10-25 公開）である。プロトコル本文は章ごとに 11 個のファイルへ分割し、章番号は 2 桁、ファイル名には章タイトルを付した。用語集・パラメータ予算、およびプロトコルの策定過程の資料は付録としてまとめ、オープンソース参加者がプロトコル本体を理解できるだけでなく、それがどのように一歩ずつ定まっていったのかも見通せるようにしている。

英語仕様は [`../../../en/specification/2025-10-25/`](../../../en/specification/2025-10-25/) にあり、**単一ファイル構成**（プロトコル本文がすべて `Faying-Protocol-1.0.md` という 1 ファイルにインライン化されており、§1–§11 と付録 A/B を含む）である。日本語との対応は**章節アンカーのレベル**での対応であって、ファイル単位の一対一対応ではない。日本語版と英語版で差異が生じた場合は簡体中国語版（zh-CN）を正とする。

## 読み方

初めて触れる場合は、まず §1 → §11 の順に本文を一通り読み、その後で付録に目を通すことを勧める。用語が不明なら付録 A を引き、タイムアウトや予算などの具体的な数値は付録 B を参照するとよい。
