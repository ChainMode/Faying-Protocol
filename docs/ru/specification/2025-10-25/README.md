# Спецификация протокола Faying Protocol/1.0

Это русскоязычная официальная спецификация Faying Protocol/1.0 (Final, опубликовано 2025-10-25). Текст протокола разбит по главам на 11 файлов с двузначной нумерацией глав и именами файлов, отражающими названия глав; краткий справочник терминологии, бюджеты параметров и материалы о процессе создания протокола вынесены в приложения, чтобы участники open-source могли как понять сам протокол, так и проследить, как он постепенно фиксировался.

Англоязычная спецификация находится в [`../../../en/specification/2025-10-25/`](../../../en/specification/2025-10-25/) и имеет **однофайловую структуру** (текст протокола полностью встроен в единственный файл `Faying-Protocol-1.0.md`, включая §1–§11 и приложения A/B); соответствие русской версии — это соответствие на **уровне якорей разделов**, а не файл-к-файлу. При расхождениях преимущественную силу имеет эталонная версия.

## Как читать

Если вы знакомитесь с протоколом впервые, рекомендуется один раз прочитать текст протокола по порядку §1 → §11, а затем обращаться к приложениям. Если термин непонятен, посмотрите Приложение A; за конкретными значениями вроде тайм-аутов и бюджетов обращайтесь к Приложению B.

## Версия

- Имя протокола: Faying Protocol (использовавшаяся в ранних черновиках аббревиатура «FAP» упразднена)

- Редакторы: Faying Protocol Committee

Номера версий во front matter всех файлов текста протокола согласованы с этим. Это первый официальный релизный срез версии 1.0, целиком мигрировавший из рабочего пространства черновика в этот каталог; русская и английская версии были опубликованы совместно в одной и той же передаче, без односторонней публикации. Последующие errata несёт новая редакция с собственной датой выпуска по §1.7.4, не меняя номер версии протокола.
